# Klasyfikacja warstw mózgowych za pomocą Random Forest

## Wymagania

- **Python**: 3.12.3
- **Pip**: 24.2
- **Pakiety**:
- pandas
- scikit-learn
- matplotlib
- joblib

Aby zainstalować wszystkie niezbędne pakiety, użyj poniższego polecenia:

```bash
pip install -r requirements.txt
```

## Opis
Projekt jest oparty na modelu klasyfikacji Random Forest, który analizuje dane statystyczne zapisane w pliku CSV. Model został zbudowany, aby klasyfikować różne kategorie danych na podstawie cech. Kod przeprowadza analizę danych, ich podział na zbiory treningowe i testowe, a następnie trenuje model, ocenia jego skuteczność i zapisuje wyniki oraz wizualizacje do plików.
